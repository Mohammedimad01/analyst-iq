# Analyst IQ — frontend

Next.js 16 App Router UI. Setup, commands and architecture are in the [root README](../README.md) and
[docs/ARCHITECTURE.md](../docs/ARCHITECTURE.md).

- `npm run dev` — dev server on :3000 (expects the API on :8000, override with `NEXT_PUBLIC_API_URL`)
- `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`
